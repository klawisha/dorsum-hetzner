# Dorsum v0.4.4 — Full Client Brand UI

## Что изменено

- Полностью переработана клиентская главная страница в фирменной стилистике Dorsum.
- Визуальный язык: почти черный фон, белая тяжелая типографика, горчичный акцент, сдержанные зеленые световые пятна.
- Hero, философия центра, принципы работы, услуги, прайс, команда, контакты и footer теперь оформлены как единая дизайн-система.
- Карусель услуг сохранена и расширена. Собственные изображения кладутся в `client/public/service-images/`.
- Команда на публичной странице теперь подгружается из `/specialists`, чтобы не хранить вымышленные имена в интерфейсе.
- Полностью переработан клиентский личный кабинет в том же визуальном языке.
- В footer добавлены тестовый адрес и телефон:
  - Павлоград, ул. Шевченка
  - +38 099 999 99 99
- Добавлен credit платформы:
  - Системный архитектор и разработчик — Владислав Косяненко
  - Администрирование и техническое сопровождение

## Фото услуг

Поместить в `client/public/service-images/`:

- `kinesiotherapy.jpg`
- `sport-massage.jpg`
- `strength-fitness.jpg`
- `shockwave.jpg`
- `vacuum.jpg`
- `stretching.jpg`

Если файла нет, карточка использует фирменный темный fallback-фон и не показывает broken image icon.

## Проверка

```powershell
cd client
npm install
npm run lint
npm run build
npm run dev
```

Проверить минимум на 390px, 768px, 1366px и 1920px.
