# Dorsum v0.5.2 — group appointment capacity

- Исправлена логика групповых услуг (`Service.groupAllowed`).
- Один специалист может вести несколько клиентов в одном слоте только если:
  - новая услуга `groupAllowed = true`;
  - все пересекающиеся записи относятся к той же услуге;
  - начало и конец сеанса полностью совпадают;
  - количество участников меньше `Service.maxClients`.
- Индивидуальные услуги по-прежнему блокируют любые пересечения специалиста.
- Клиент не может иметь две пересекающиеся записи независимо от типа услуги.
- `SpecialistBlock` по-прежнему полностью блокирует создание записи.
- Добавлен PostgreSQL advisory transaction lock, защищающий вместимость группы от конкурентных запросов.
- `/appointments/available` теперь принимает `serviceId` и корректно считает специалиста доступным для незаполненного группового сеанса.
- Форма создания занятия передаёт `serviceId` в availability API и показывает вместимость групповой услуги.
- Admin service PATCH теперь поддерживает `groupAllowed` и `maxClients`.
