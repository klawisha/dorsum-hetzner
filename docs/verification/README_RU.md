# Фактические результаты 2.1.0

11 модульных и 25 интеграционных тестов прошли; 2 проверки настоящей конкурентности пропущены локально и включены в CI PostgreSQL 18.
Интеграция выполнена через Prisma с PostgreSQL WASM (PGlite), не с обычным сервером PostgreSQL.
Все 23 миграции применены с нуля. Проверка обновления 20 → 23 на синтетической старой БД сохранила деньги, остатки, ставки и байты изображений.
48 проверок интерфейса в Chromium с синтетическими API-ответами, шесть ширин от 320 до 1440 px, без зафиксированных ошибок.
ESLint, production build и Prisma validate прошли. Предупреждение сборщика о размере JS-бандла не блокирует сборку.
Оба npm audit: 0 известных уязвимостей на дату проверки.
20 исторических миграций побайтно совпадают с исходным архивом.

Обычный PostgreSQL, Docker/Caddy, реальный VPS, DNS, production-дамп, внешний backup и физические устройства требуют проверки на инфраструктуре пользователя. CI подготовлен, но удалённый запуск здесь не выполнялся.

26 октября 2026 исправлен конфликт статического адреса Caddy с автоматической выдачей Docker IP. Проверены YAML, непересечение адреса Caddy и автоматического диапазона, синтаксис команд и повторное безопасное применение исправления к прежнему compose.yml. Проверка подключения Caddy в CI теперь выполняется после запуска API. Фактический Docker-запуск и удалённый CI для этой правки здесь не выполнялись; см. network-fix.txt и docs/NETWORK_FIX_RU.md.
