# Dorsum v04 — responsive + session refresh

## Изменения
- Убрана глобальная белая рамка: `#root` теперь занимает весь viewport без border/max-width.
- Усилен responsive layout для телефона, планшета, ноутбука и desktop.
- Finance/Users/Clients таблицы на телефоне превращаются в карточки вместо сжатой desktop-таблицы.
- Courses Management переходит с 2 колонок на 1 на мобильных устройствах.
- Добавлен автоматический refresh access token: access token = 15 минут, refresh token = 7 дней; при 401 клиент один раз обновляет токены и повторяет исходный запрос. Параллельные 401 используют один refresh request.
- Logout очищает access/refresh/user.
- В каталог заложена отдельная услуга `Силовой фитнес с реабилитологом`, но она намеренно `active=false` с нулевой ценой/выплатой до получения точных финансовых значений. Это предотвращает случайную бесплатную запись в production.

## Важно после deploy
Пользователям, которые вошли ДО этого обновления, нужно войти заново один раз: старый frontend не сохранял refreshToken. После нового входа сессия будет автоматически продлеваться до истечения refresh token.

## Силовой фитнес
Для безопасной активации нужны два точных числа:
1. цена разового занятия;
2. выплата специалисту за такое занятие.
После их установки в `server/src/modules/services/catalog.js` заменить `active=false` на `true` и выполнить seed endpoint / перезапустить API (ensureServiceCatalog создаст отсутствующую запись; для уже созданной неактивной записи используйте admin seed-price-list, чтобы обновить ее).
