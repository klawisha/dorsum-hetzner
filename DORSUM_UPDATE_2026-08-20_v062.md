# Dorsum v0.6.2 — clean calendar rebuild from stable v0.5.7

- База откатана к v0.5.7, где mobile time-grid scroll работал корректно.
- Полностью исключены axis/table overrides из v0.5.8–v0.6.1.
- Никакой timezone-логики не добавляется.
- Время занятий/даты работают ровно по старой стабильной схеме проекта.
- Диапазон календаря: 07:00–20:00 включительно.
- `slotMaxTime=20:30`, поскольку FullCalendar трактует max как exclusive.
- Убрано только отрицательное смещение time label (`top:-8/-7`).
- Ширины внутренних таблиц/colgroup FullCalendar не переопределяются.
- `$` и status вынесены в отдельную правую lane внутри event-card.
- Для badge lane резервируется padding, поэтому текст физически не может попасть под `$`.
- На узких параллельных событиях сначала скрывается redundant status, затем второстепенные строки.
