# Dorsum v0.5.4 — contextual group booking UX

- Клиент и специалист с одним и тем же `userId` больше не могут одновременно отображаться как доступные роли в форме записи.
- Выбор клиента исключает его же профиль специалиста; выбор специалиста исключает его же профиль клиента.
- `/appointments/available` теперь возвращает `joinableGroupSessions`.
- Специалист с уже начатой группой в выбранное время остаётся доступным, если в группе есть места.
- После выбора такого специалиста услуга автоматически фиксируется на услуге существующей группы.
- Вместо полного прайса показывается карточка текущей группы: услуга, занято/максимум, свободные места.
- Длительность фиксируется длительностью существующей группы.
- Добавлена кнопка «Добавить в группу» вместо обычного «Создать».
- `GROUP_SESSION_FULL`, `TIME_SLOT_BUSY`, `CLIENT_TIME_SLOT_BUSY`, `SPECIALIST_UNAVAILABLE` показываются человеческими сообщениями внутри формы без browser alert.
- AppointmentController теперь сохраняет корректный HTTP statusCode (например 409 conflict), заданный сервисным слоем.
- Проверка `maxClients` и PostgreSQL advisory lock из v0.5.3 сохранены.
