# DORSUM — прайс, скидки, выплаты специалистам и касса

## После распаковки
1. Сохраните свой `server/.env`.
2. В `server`:
   - `npm install`
   - `npx prisma migrate deploy` (production) или `npx prisma migrate dev` (local development)
   - `npx prisma generate`
   - `npm run dev`
3. В `client`:
   - `npm install`
   - убедитесь, что `VITE_API_URL` указывает на API
   - `npm run dev`

При первом запуске API недостающие позиции прайс-листа добавляются автоматически. Существующие позиции с тем же названием НЕ перезаписываются, поэтому цену и `specialistPayPerSession` можно менять прямо в БД — рестарт не вернёт старые значения.

## Скидки
- военный: разовая услуга 10%, курс 20%;
- пенсионер: 15% всегда;
- если отмечены обе категории, применяется большая из доступных скидок (не суммируются).

## Касса
`GET /finance/summary?period=day` и `period=month`.
В кассу попадает сумма по дате фактической отметки оплаты (`paidAt`).
Занятие по уже оплаченному курсу повторно в кассу не попадает. Сам курс попадает в кассу в день его оплаты.

## Зарплата
Начисляется только за `COMPLETED` занятия. Ставка фиксируется в `Appointment.specialistPay` при записи, поэтому изменение ставки услуги в БД не переписывает историю.
- занятия с реабилитологом: 120 грн/занятие;
- массаж 30 мин: 150;
- массаж 60 мин: 250;
- массаж 90 мин: 350;
- антицеллюлитный массаж: 500.
Ставки лежат в `Service.specialistPayPerSession` и могут редактироваться в БД.

## Окна отсутствия
Специалист на своей странице может создать интервал отсутствия. API запрещает создать окно поверх существующего занятия и запрещает записать клиента поверх окна.
