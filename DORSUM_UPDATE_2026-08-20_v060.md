# Dorsum v0.6.0 — centre timezone + time axis containment

- Расписание центра теперь привязано к `Europe/Kyiv`, а не к timezone устройства.
- Ввод 08:00 всегда создаёт 08:00 по Киеву, независимо от ПК/телефона администратора.
- API по-прежнему получает и хранит корректный UTC instant.
- При чтении из API события преобразуются обратно в wall-clock Dorsum/Europe-Kyiv перед передачей FullCalendar.
- Исправлен сценарий, когда одна и та же запись могла отображаться как 08:00 на одном устройстве и 18:00 на другом.
- Временная ось полностью удерживает HH:MM внутри своей колонки; `overflow: visible` удалён финальными override-правилами.
- Desktop axis 66px, mobile 58px, small mobile 56px.
- Рабочий диапазон остаётся 07:00–20:00 включительно.
