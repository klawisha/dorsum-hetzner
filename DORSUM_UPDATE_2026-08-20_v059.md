# Dorsum v0.5.9 — time axis + payment badge layout fix

- Календарь работает с 07:00 до 20:00 включительно.
- `slotMaxTime` технически выставлен в 20:30, потому что FullCalendar трактует max time как exclusive.
- Исправлена причина визуального `11:00 -> 1:00`: axis column больше не сжимается и не режет первую цифру.
- Для desktop axis = 76px, mobile = 68px, small mobile = 64px.
- Убраны отрицательные/transform смещения time label.
- `$` больше не делит одну строку с временем. Для него резервируется отдельная зона справа.
- Текст физически не может зайти под badge.
- На узких параллельных событиях скрывается вторичный status badge, затем service/specialist.
- На сверхузких событиях сохраняются время, клиент и компактный `$`.
