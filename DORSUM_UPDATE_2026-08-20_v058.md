# Dorsum v0.5.8 — calendar event badge + working hours polish

- Рабочий диапазон календаря изменён на 07:00–20:00.
- Начальный scrollTime изменён на 07:00.
- Исправлено подрезание первой/последней подписи времени на mobile.
- Удалено отрицательное смещение `top:-8px` у time labels.
- Подписи времени теперь вертикально центрируются внутри 30-минутного слота.
- Event badges вынесены в отдельную grid-колонку, текст больше не может заходить под `$`/status.
- Для очень узких параллельных событий status badge скрывается первым, `$` сохраняется как более важный индикатор оплаты.
- На сверхузких карточках автоматически скрываются второстепенные поля услуги/специалиста, сохраняя время и клиента.
